# Луч Маяка

Обучение операторов клиентского сервиса «Лучи». Карта пути и первые пять дней.

---

## 1. Что в папке

```
index.html    ← карта пути: вход, письмо, паромщик, десять островов, компас, почта, штаб
day1.html     ← День 1 · Туман
day2.html     ← День 2 · Прилив
day3.html     ← День 3 · Штиль
day4.html     ← День 4 · Мель
day5.html     ← День 5 · Прибой
```

Шесть файлов, больше ничего. Каждый день — самостоятельная страница: шрифты, картинки
и вся логика лежат внутри неё. Поэтому файлы тяжёлые (1–2 МБ), зато ничего не может
«отвалиться» и страницу можно открыть даже без интернета.

Острова VI–X (Маяк, Гряда, Фарватер, Створ, Посвящение) пока проходятся прямо на карте —
задания к ним коуч заводит в таблице. Когда появятся отдельные страницы, они лягут рядом
файлами `day6.html` и дальше, и карта подхватит их сама.

---

## 2. Заливаем на GitHub

1. github.com → **New repository**.
2. Имя, например `luch-mayaka`. Тип — **Public** (бесплатные Pages работают только с публичным).
3. Галочку «Add a README» не ставь — сразу **Create repository**.
4. На пустой странице репозитория → **uploading an existing file**.
5. Перетащи в окно браузера все шесть файлов сразу.
6. Внизу — **Commit changes**.

Файлы крупные, загрузка займёт минуту-другую. Если GitHub ругается на размер — заливай
по два-три файла за раз, лимит на один файл 25 МБ, мы в него укладываемся с запасом.

---

## 3. Включаем сайт

1. Репозиторий → **Settings** → слева **Pages**.
2. Source: **Deploy from a branch**.
3. Branch: **main**, папка **/ (root)** → **Save**.
4. Подожди одну-две минуты, обнови страницу — сверху появится адрес.

```
https://ТВОЙ-НИК.github.io/luch-mayaka/           ← карта
https://ТВОЙ-НИК.github.io/luch-mayaka/day1.html  ← сразу День 1
```

Давать людям надо **адрес карты**. Всё остальное они найдут сами.

---

## 4. Как это работает вместе

- Человек заходит на карту, вводит логин и пароль.
- Выбирает звезду — открывается карточка острова: сколько минут, сколько испытаний, сколько монет.
- «Войти в остров» уводит на страницу дня (`day1.html` и так далее).
- В углу страницы дня — кнопка **«К карте»**. Она возвращает обратно, вход заново вводить не надо:
  логин живёт в памяти вкладки.
- Внизу дня, после «День пройден», появляется вторая кнопка — **«Вернуться на карту»**.

Режим коуча включается добавлением `?coach=1` к адресу дня — тогда снимаются блокировки
и можно листать вперёд, не проходя задания:

```
https://ТВОЙ-НИК.github.io/luch-mayaka/day3.html?coach=1
```

---

## 5. Что можно править и чего нельзя

**Можно.** Тексты карточек островов, время, описания — они живут в таблице, страницы трогать не нужно.

**Не надо.** Переименовывать файлы. Карта ищет дни строго по именам `day1.html` … `day5.html`,
а дни ищут карту по имени `index.html`. Переименуешь — перестанут находить друг друга.

**Нельзя.** Класть дни в подпапки вроде `days/day1.html` — ссылки перестанут работать.
Все шесть файлов лежат рядом, в корне.

---

## 6. Если что-то не так

**Открывается белая страница.** Значит, файл не долился целиком. Залей его заново.

**«К карте» ведёт в никуда.** Проверь, что файл карты называется именно `index.html`,
маленькими буквами. GitHub различает `Index.html` и `index.html`, компьютер — нет.

**Правки не видно.** Обнови страницу с **Ctrl+F5** (на Маке **Cmd+Shift+R**). Браузер держит старую версию.

**Нужен свой домен вместо github.io.** Settings → Pages → Custom domain, дальше у регистратора
домена CNAME на `ТВОЙ-НИК.github.io`.

---

## 7. Что дальше

Сейчас страницы дней ничего не пишут в таблицу — прогресс живёт в браузере читателя,
монеты на карте считаются по заданиям из таблицы. Следующий шаг — связать одно с другим
через Apps Script: день закончился, звёзды посчитались, монеты и время ушли в журнал,
а карта показала это на компасе. Файлы к этому готовы, дописывать нужно только скрипт.
